# UX Wireframe Descriptions

## 1) Global Shell
- Left sidebar: workspace navigation and datasource switcher.
- Top bar: global search, theme toggle, profile menu.
- Main canvas: context-driven content with persistent insight drawer.

## 2) Authentication Screens
- Split layout.
- Left: product message and feature highlights.
- Right: login/register cards with progressive disclosure.

## 3) Workspace (AI Copilot)
- Left column: conversation timeline.
- Center: generated SQL/query + result table tabs.
- Right: chart preview and narrative panel.
- Footer composer: natural language prompt input and send actions.

## 4) Datasource Manager
- Card grid per connector type.
- Inline status indicators: connected, error, stale metadata.
- Quick actions: test, sync schema, edit credentials.

## 5) Dataset Explorer
- Top: table selector.
- Mid: schema table (column, type, semantic tag).
- Bottom tabs: preview rows, profile stats, anomalies.

## 6) Semantic Layer Editor
- Left: semantic tables tree.
- Main: editable business labels and definitions.
- Right drawer: relationships and KPI formula builder.

## 7) Dashboard Builder
- Toolbox of widget templates.
- Drag-drop responsive grid canvas.
- Widget config modal with query, axes, filters, style options.

## 8) Motion and Feedback
- Skeleton loading on all data-heavy panels.
- Soft enter transitions for generated insights.
- Progress status chips during AI steps.
- Hover elevation and border glow for active widgets.
